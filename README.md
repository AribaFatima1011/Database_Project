# Faculty Management System

## Project Overview

The **Faculty Management System** is a database management project designed to manage and organize faculty-related information efficiently. The system stores and manages data related to departments, faculty members, courses, attendance, leave, and salary.

## Features

- Faculty information management
- Department management
- Course management
- Attendance records
- Leave management
- Salary management
- SQL queries for data retrieval and management
- Relational database design

## Database Structure

The project includes the following main entities:

- Admin
- Department
- Faculty
- Course
- Attendance
- Leave
- Salary

## Technologies Used

- SQL
- Relational Database Management System (RDBMS)

## Project Documentation

The complete project documentation is available in the project files, including database design, tables, SQL queries, and project details.

## Purpose

This project was developed to demonstrate practical knowledge of **Database Management Systems (DBMS)**, relational database design, SQL queries, and data management.
